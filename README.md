# Apex GT Circuito

Proyecto web del circuito Apex GT, actualizado en octubre de 2026.

## Contenido

- `src/`: código fuente de la aplicación.
- `public/`: recursos públicos y multimedia.
- `dist/`: compilación distribuible.
- `package.json`: configuración y scripts del proyecto.

## Ejecución local

Instala las dependencias y ejecuta el servidor de desarrollo:

```bash
npm install
npm run dev
```

Para generar una compilación de producción:

```bash
npm run build
```
